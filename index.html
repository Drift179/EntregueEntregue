1 Ativar Login no Firebase Authentication

No console do Firebase (Authentication → Sign-in method), habilite os provedores:

  • E-mail/senha (Ativar)

2 Regras do Realtime Database (/pedidos e /usuarios)

Em Realtime Database → Regras, cole a estrutura abaixo para permitir leitura/escrita para usuários autenticados e proteção ao entregador oficial:

{
  "rules": {
    "usuarios": {
      "$uid": {
        ".read": "auth != null",
        ".write": "auth != null && auth.uid === $uid"
      }
    },
    "pedidos": {
      ".read": "auth != null",
      ".write": "auth != null"
    }
  }
}
